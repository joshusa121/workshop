# 법인전환 컨설팅 실무 조사 (2026-09-01)

제품 1번 「법인전환 시뮬레이터」 설계 근거. 출처는 세무·회계법인 블로그 — **모든 수치는 착수 시 법제처·국세청 원문으로 재확정할 것.**

## 실무 컨설팅 구성 (검토보고서 목차)

1. 법인전환 필요성 검토
2. 적정 시기 검토
3. 개인사업자 가치평가·양수도금액 산정
4. 절세효과 시뮬레이션
5. 전환 방법 선택
6. 실행 로드맵 (설립→양수도→폐업→승계)

시장 가격: 시뮬레이션만 30~100만 원, 자문 100~300만, 종합 컨설팅 200~500만.

## 실무 판단 기준 수치 (검증 필요)

- 과세표준 8,800만 초과 → 검토 시작 / 순이익 2억 초과 → 적극 권장
- 성실신고확인대상 매출 기준: 도소매 15억 / 제조 7.5억 / 서비스 5억 — 대상 전 전환 유리, 이후 전환 시 법인에서 3년간 성실신고확인서 제출
- "2026년 법인세율 1%p 인상" 주장 존재 — 원문 확인 필요

## 세율 비교 외 변수 (제품 차별화 지점)

- 건강보험료: 지역가입 → 직장가입 변화
- 대표 급여 설계, 배당 전략
- 법인 유지비용: 기장료 증가(연 120~360만), 법인세 신고비 (연 50~100만)
- 전환 비용: 취득세·양도세(이월과세 여부), 등록면허세(과밀억제권역 중과), 감정평가·법무 수수료
- 세금 외: 대출·거래처 신뢰도, 개인자산 분리, 승계 계획

## 전환 방법 4가지

| 방법 | 특징 | 핵심 요건/비고 |
|---|---|---|
| 폐업 후 신규설립 | 가장 단순, 자산 승계 없음 | 자산·부채 적을 때 |
| 일반 사업양수도 | 자산·권리 이전 | 감면 없음 |
| 세감면 포괄양수도 | 양도세 이월과세·취득세 감면 | 자본금 ≥ 개인 순자산가액 |
| 현물출자 | 자산을 자본금으로 출자 | 감정평가·법원 절차, 비용·시간 大 |

## 흔한 실수 (제품 경고 포인트)

- 직원 고용승계·퇴직금 처리 누락 → 근로계약 불이행, 4대보험 재등록 문제
- 자산 보유 상태에서 세무검토 없이 전환 → 양도세·취득세 폭탄
