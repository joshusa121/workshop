# 주택 양도세 손계산 fixture

엔진과 독립적으로 `cgt-facts.md`·`2026-tax-facts.md`(§55① 세율표) 수치만 써서 계산했다.  
계산자: Claude (세션 2) / 날짜: 2026-09-26 / 금액은 전부 가공값.  
단수: 과표 1원 미만 버림, 산출세액·지방소득세 10원 미만 버림(1화 Josh 규칙 준용). 안분 계산 중간값은 원 단위 버림.  
기간: 취득일을 첫날로 센다(초일산입). n년은 n년째 응당일의 **전날**에 채워진다(예: 2023-09-02 취득 → 2026-09-01 양도 = 3년). 홈택스 장특 계산기로 확인(cgt-cross-check.md X5·X6). 아래 fixture는 모두 응당일에서 떨어진 날짜라 이 규칙 변경의 영향을 받지 않는다.  
공통: 등기 자산, 국내 거주자, 같은 해 다른 양도 없음(기본공제 250만 전액), 감면 없음.

§55① 누진 계산 참고: 5,000만 이하 84만+15% / 8,800만 이하 624만+24% / 1.5억 이하 1,536만+35% / 3억 이하 3,706만+38% / 5억 이하 9,406만+40% / 10억 이하 1억7,406만+42% / 초과 3억8,406만+45%.

## F5 — 2주택, 조정대상지역 주택 양도 (중과 유예 전/후)

| 입력 | 값 |
|---|---|

**(a) 중과** — 장특공제 배제(§95② 괄호), 세율 §55① + 20%p (§104⑦1호):

| 단계 | 계산 | 값 |

**(b) 유예 적용(2026-05-09 이전 양도)** — 중과 제외 → 일반세율 + 표1. 보유 2020-01-15~2026-04-30 = 6년 3개월 → 6년 12%. F4와 동일: 산출 113,860,000 / 지방 11,386,000.

분기 기준일(2026-05-09)은 Josh 승인(2026-09-26) 후 테스트에 고정. (a)는 홈택스 간편계산과 일치(cgt-cross-check.md X2).

**(c) 3주택 이상(+30%p)** — (a)와 같고 세대에 분양권(2022 취득) 1개 추가: 14,000,000×36% = 5,040,000 / 36,000,000×45% = 16,200,000 / 38,000,000×54% = 20,520,000 / 62,000,000×65% = 40,300,000 / 150,000,000×68% = 102,000,000 / 97,500,000×70% = 68,250,000 → **252,310,000**, 지방 25,231,000.

**(d)** 다른 주택이 지방 저가 주택(수도권·광역시 밖, 기준시가 3억 이하)이면 중과 주택 수에서 빠져 중과 없음 → F4와 같음(113,860,000).

**(e) 다목 경과조치** — 계약 2026-05-01(비허가, 4개월 지역): 4개월 이내 = 2026-08-31까지. 08-31 양도 유예, 09-01 양도 중과. 계약 2026-05-10이면 불가.

**(f) 나목 경과조치** — 허가 신청 2026-05-08, 계약 2026-06-01(5-10 이후 계약), 6개월 지역: 2026-11-09까지 양도 유예, 11-10 중과. 허가 신청 2026-05-10이면 불가.

**(g) 조정지역 2주택 + 보유 1년** — 취득 2025-06-01 / 8억, 양도 2026-09-01 / 9억. 과표 97,500,000. 60% = 58,500,000 / 중과 = 14,000,000×26% + 36,000,000×35% + 38,000,000×44% + 9,500,000×55% = 3,640,000 + 12,600,000 + 16,720,000 + 5,225,000 = 38,185,000 → 큰 세액 **58,500,000**(§104⑦ 후단).
