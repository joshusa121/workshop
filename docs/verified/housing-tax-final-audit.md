# 주택 세금 통합 계산기 — 최종 감사

확인일 2026-10-17 / 세율 버전 `2026-10-17.1`.

## 구현 범위

- 개인 거주자·일반주택·단독명의의 신규 유상취득과 2026년 보유세를 구분한다.
- 취득세 일반 6억·9억 구간, 개인 다주택 8·12% 중과, 사용자 적격 확인형 일시적 2주택, 지방교육세·농어촌특별세를 계산한다.
- 재산세는 주택별 공시가격·공정시장가액비율·일반/1주택 특례세율·도시지역분·지방교육세를 계산한다.
- 종부세는 개인별 공시가격 합산·기본공제·공정시장가액비율·주택 수별 누진세율·재산세 중복공제·고령/장기보유 공제·농특세를 계산한다.
- 금액·비율·보고서의 나이/보유연수/취득 주택 수에 Traced 근거 팝오버를 제공한다. 결과는 일회성/연간 표로 구분하며 서로 합산하지 않는다.
- 양도세는 기존 `/tools/capital-gains`로 연결한다.

## 근거 확정

법제처 Open API 검색→MST 본문 XML을 직접 조회했다. 식별자·시행일·산식·예외는 [법령 확인](housing-tax-facts.md)에 기록했다. 모든 제품 Basis.url은 사람이 여는 `law.go.kr/법령/.../제...조` 링크이며 조회용 계정 파라미터는 포함하지 않는다. 독립 [손계산](housing-tax-hand-calc-fixtures.md) 10건과 추가 경계값을 테스트에 고정했다.

## 브라우저·인쇄 실측

프로덕션 `next start`와 Chromium으로 직접 확인했다.

- `/tools/housing-tax` HTTP 200. 기본 가상 예시 일회성16,500,000원·연간1,512,000원.
- 취득가액6억원으로 변경 시 일회성6,600,000원. 금액 팝오버에 계산 과정과 지방세법 제11조 사람용 링크 노출.
- 공시15억원·만70세·보유15년 입력 시 연간3,622,920원. 공유 URL의 입력 복원 및 보고서 금액 일치.
- 공유 링크 복사 후 클립보드 URL을 다시 열어 원래 입력 복원. 구세율 버전 보고서는 현재 세율 재계산 안내.
- 금액 입력을 비우면 결과·보고서 링크를 숨기고 공유 복사를 비활성화. 주택 추가·제외 동작 확인.
- 손상/누락 링크의 보고서는 결과표를 생성하지 않음. 손상 링크 계산기도 결과표를 숨기고 명시적 「가상 예시로 새로 시작」 버튼 제공. 초기 경고가 새 시작 후 남는 문제는 수정 후 재실측: 경고0개.
- 보고서 robots=`noindex, nofollow`, 인쇄/PDF 버튼 및 입력 화면 복귀 링크 제공.
- 양도세 링크를 실제 클릭해 `/tools/capital-gains` 이동 및 제목 확인.
- 1440px 데스크톱, 390px·320px 모바일에서 스크린샷 검토. 가로 넘침0, 브라우저 pageerror0.
- 예시 보고서 PDF A4 3쪽 생성 후 모든 페이지를 PNG로 렌더해 눈으로 확인. 금액·행 잘림 없음. 나이·보유기간·선택 가정·미반영·DISCLAIMER도 인쇄됨. 인쇄 시 팝오버는 숨김.
- 디자인 자기비평: 3화의 지면형 좌입력·우결과, 기존 색·글꼴·선 토큰을 유지했다. 동일 카드 반복이나 장식용 배지는 추가하지 않았다. 표에서 일회성/연간 차이를 읽을 수 있으며 미반영 경고가 금액 앞에 보인다.

검증 중 임시 이미지/PDF는 `/tmp/housing-desktop.png`, `/tmp/housing-mobile.png`, `/tmp/housing-mobile-320.png`, `/tmp/housing-report.pdf`, `/tmp/housing-final-pdf-1.png`부터 3.png에 저장했다. 임시 브라우저 스크립트·API 원문은 저장소에 추가하지 않았다.
