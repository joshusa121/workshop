## 미반영·Josh 감수 필요

1. 성실신고 대상·기장의무·추계 적격 여부, 외부세무조정 해당 여부의 자동 판정.

3. 홈택스 자동작성·전자신고 대체서식·제출 생략, 추계 계산서 제출 갈음의 실제 적용 확인. 실측 미대조.
4. 귀속연도별 부칙·경과규정. 검색 응답 시행일과 본문 조문시행일 표기가 다른 점은 facts에 기록했다.

6. 지방소득세·세액·신고기한 계산, 실제 서류 업로드·신고서 제출은 포함하지 않는다.
7. 카탈로그·홈 등록과 배포는 오케스트레이터 담당. 현재 저장소에는 remote가 없어 origin 차이 확인 불가.
