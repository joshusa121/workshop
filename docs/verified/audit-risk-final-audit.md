# 세무조사 리스크 체크 — 최종 감수 기록

작성일 2026-10-17. 버전 `2026-1`.

## 범위

개인·법인사업자의 현금수입, 가공경비 의심, 법인 대표 가지급금, 기업업무추진비 한도초과, 무자료 매입 및 신고·확인서 의무 이행을 점검한다. 실제 세무조사 대상 확정·추징세액 산출은 하지 않는다.

## 법령 검증

- 법제처 Open API로 국세기본법·소득세법·법인세법을 검색한 후 MST 본문을 직접 조회했다. 확인 기록·본문 해시는 `audit-risk-facts.md` 참조.
- 사전통지 근거를 국세기본법 제81조의7로 바로잡았다. 제81조의2는 납세자권리헌장이다.
- 모든 Basis.url은 사람용 법제처 조문 링크이며 API 인증 식별자가 없다.
- 법률에 없는 위험점수·확률·업종 평균·금액 면책기준을 탑재하지 않았다. 분류는 `assumption`으로 표시한다.

## 구현 검증

- 숫자는 Traced로 추적한다. 원 금액은 공용 TraceValue, 비중·개수는 제품 전용 팝오버를 사용한다.
- 독립 손계산 9건: 0과 양수 경계, 100% 현금, 1원 무자료 매입, 원 미만 절사, 개인 적용 제외, 의무 미확인 포함.
- 공유 링크는 형식·데이터·기준 버전을 검증하고 누락값을 자동 보충하지 않는다.
- 입력 미완료 시 결과를 만들지 않는다. 손상 링크는 복구 안내, 보고서 단독 접근은 입력 링크 안내를 표시한다.
- 보고서는 noindex, 인쇄/PDF 버튼, 작성일·버전·DISCLAIMER·전제와 미반영을 포함한다.
- 전체 테스트·빌드·화면 검증 결과는 아래 최종 실행 결과에 기록했다.

## 미반영 및 Josh 감수 필요

- **Josh 감수 필요:** 검토 우선순위 분류가 실제 상담 흐름에 적절한지. 우선 검토와 자료 점검은 법정 등급이 아니다.
- **Josh 감수 필요:** 현금수입 신고 대조, 실제 가공거래 여부, 증빙 수취 예외, 업무 관련성, 이미 반영한 세무조정, 의무 적용 여부.
- 성실신고확인 업종별 수입금액 기준·대상 판정, 법인 성실신고확인 대상 판정, 접대비 한도 계산, 가산세·인정이자·지급이자 제한·소득처분·추징세액은 미반영.
- 무작위 조사, 외부 과세자료, 탈세 제보, 과거 신고 이력·업종별 분석·조세범칙조사는 미반영. 입력상 징후가 없어도 세무조사가 가능하다.
- 비거주자·해외거래·특수 업종·귀속시기·경과규정의 개별 판단은 다루지 않는다.
- 같은 경비가 여러 지표에 겹칠 수 있어 총 위험금액을 계산하지 않는다. 비율은 사용자 추정치이며 실제 가공 금액의 확정치가 아니다.
