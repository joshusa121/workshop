# 부가가치세 계산기 — 법제처 원문 대조 (5화)

작성: 세션 1, 2026-10-16. 부가가치세법 [시행 2026-01-02] 법률(MST 276117), 부가가치세법 시행령 [시행 2026-04-01] (MST 283641). 법제처 Open API 원문.
확인 방법: `law.go.kr/DRF/lawService.do?OC=…&target=law&MST=…`.

## 세율·계산 구조
- **세율 10%** — 부가가치세법 §30.
- **매출세액** = 과세표준(공급가액) × 10% — §37①.
- **납부세액(일반과세)** = 매출세액 − 매입세액. 매출세액 초과 매입세액은 환급 — §37②.

## 신고·납부 기한
- **예정신고** (§48①): 제1기 1/1~3/31 → **4/25까지**, 제2기 7/1~9/30 → **10/25까지**.
- **예정고지** (§48③): 개인사업자는 직전 과세기간 납부세액의 **50%**를 예정신고기간 종료 후 25일까지 고지·징수(개인은 신고 대신).
- **확정신고** (§49①): 과세기간 종료 후 25일 이내 → 1기 **7/25**, 2기 다음해 **1/25**.

## 간이과세 (부가가치세법 제7장)
- **적용 범위** (§61①·시행령 §109①): 직전 연도 공급대가가 **8천만원 이상 1억 400만원 미만**인 개인사업자. (8천만 = 4,800만×? 아님 — 법문은 "8천만원부터 1억400만원 미만")
- **간이과세 배제 업종** (§61①·§109②): 광업, 제조업(일부), 도매업·상품중개업, 부동산매매업, 과세유흥장소 일부, 부동산임대업 일부, 변호사·세무사·회계사 등 전문직 등.
- **간이 납부세액** (§63②) = **공급대가 × 업종별 부가가치율 × 10%**.
- **세금계산서 매입 세액공제** (§63③1호) = 세금계산서등을 발급받은 재화·용역의 **공급대가 × 0.5%**. (2020년 개정으로 "매입세액 전액 공제"가 아니라 0.5% 정액 공제로 변경됨 — 원문 확인)
- **납부의무 면제** (§69①): 공급대가 합계액이 **4,800만원 미만**이면 §63② 납부의무 면제(§64 재고품 매입세액 가산은 예외).
- **예정부과** (§66①): 직전 과세기간 납부세액의 **50%**(1천원 미만 버림).

|---|---|
| 소매업, 재생용 재료수집 및 판매업, 음식점업 | 15% |
| 제조업, 농업·임업·어업, 소화물 전문 운송업 | 20% |
| 숙박업 | 25% |
| 건설업, 운수 및 창고업(소화물 전문 운송업 제외), 정보통신업 | 30% |
| 금융·보험 관련 서비스업, 전문·과학 및 기술서비스업(인물사진·행사영상 촬영업 제외), 사업시설관리·사업지원 및 임대서비스업, 부동산 관련 서비스업, 부동산임대업 | 40% |

## v0.1 범위 (제안 — Phase 0 체크포인트)
- 입력: 업종(위 표) · 연간 매출 **공급대가(부가세 포함)** · 세금계산서 수취 매입 공급대가.
- 출력: 일반과세 납부세액(매출세액 − 매입세액) vs 간이과세 납부세액(공급대가×부가가치율×10% − 세금계산서매입×0.5%) · 차액 · 간이 적용 가능/납부면제 여부 · 권고.
