# 창업 감면 독립 손계산 fixture

2026-10-17. 엔진·세율 상수·공용 계산 함수를 호출하지 않고, 법제처 API 확인표의 비율과 정수 곱셈·나눗셈으로 직접 작성했다. 기대값은 테스트에 숫자 리터럴로 고정했다.

공통 전제: 신규 창업·중소기업·제조업·역년 결산·요건 확인, 특수사례 없음, 최초 소득 2026년, 계산 2026년, 창업 2026-01-01, 연환산 수입 200,000,000원, 대상 사업 국세 산출세액 10,000,000원. 각 행은 아래 차이만 바꾼다. 최저한세 등 반영 전 감면액이다.

추가 독립 경계 검증:

- 2027-12-31 창업은 일몰 포함, 2028-01-01 창업은 현행 규정상 제외.
- 2026 창업 후 계속 무소득: 2026+5=2031 기산, 2031+4=2035 종료(예정). 실제 소득이 먼저 생기면 앞당김.
- 2033에 처음 소득이 생겨도 기산 연도는 2031, 따라서 2036은 종료 후.
- 법인전환·동종 재창업·사업 확장은 창업 제외. 사업 승계는 예외가 있으므로 감면 0으로 단정하지 않고 금액 미확정.
- 2024 이전 창업에는 2025 신설 한도를 소급 계산하지 않고 감수로 전환.
- 산출세액 0원도 0원과 조문 근거 유지. 음수·무한대·비정수 원·불가능한 날짜·소득 연도 모순은 금액 미확정.
