## 성실신고: 당해 연도

영 §133① 기준: 도소매 등 1,500,000,000 / 제조·음식 등 750,000,000 / 임대·서비스 등 500,000,000. **이상**이므로 기준과 같으면 대상이다.

| 사례 | 해당 연도 수입 | 직접 비교·환산 | 기대 |
|---|---:|---|---|
| 1 도소매 직전 | 1,499,999,999 | 15억보다 1원 적음 | 비대상 |
| 2 도소매 경계 | 1,500,000,000 | 15억과 같음 | 대상 |
| 3 제조·음식 직전 | 749,999,999 | 7.5억보다 1원 적음 | 비대상 |

| 5 임대·서비스 직전 | 499,999,999 | 5억보다 1원 적음 | 비대상 |

## 복식부기: 직전 연도

영 §208⑤2·⑦. 도소매 3억 / 제조 1.5억 / 서비스 7,500만원 **미달**이면 간편장부. 직전 수입 각각 299,999,999 / 149,999,999 / 74,999,999는 복식부기 비대상, 기준과 같은 300,000,000 / 150,000,000 / 75,000,000은 대상.

겸업: 도소매 150,000,000 + 서비스 37,500,000 × (300,000,000/75,000,000) = 300,000,000 → 복식부기 대상.

당해 도소매 15억·직전 0원: 성실신고 대상이지만 직전연도 기준 복식부기는 비대상. 두 의무를 서로 대신하지 않는다.
신규 사업자는 간편장부, 간편장부 배제 전문직이면 신규라도 복식부기. 신규인데 직전 수입을 입력해도 신규 예외가 먼저다.

## 확인비용 공제 계산상 한도

대상자이고 확인서 제출을 선택한 전제. 조특법 §126의6①, 영 §121의6①1. `min(직접 확인비용 × 60%, 1,200,000)`.

| 직접 확인비용 | 손계산 | 계산상 한도 |
|---:|---|---:|
| 1,000,000 | 1,000,000 × 60 / 100 | 600,000 |
| 2,000,000 | 1,200,000 = 한도 | 1,200,000 |
| 3,000,000 | 1,800,000이나 한도로 제한 | 1,200,000 |
| 0 | 0 × 60% | 0 |
| 1 | 0.6원, 표시·추정은 원 미만 버림 | 0 |

비대상/확인서 미제출이면 공제 적용 안내를 하지 않고 0 표시. 실제 공제액과 원 미만 실무 처리는 Josh 감수. 실제 세액·공제 배제·이월 계산은 하지 않는다.

## 큰 금액 표시 회귀

단일 도소매 현재 수입 999,999,999,006원은 다른 업종이 없으므로 환산액도 정확히 999,999,999,006원. 직전 수입 999,999,999,000원도 동일하게 유지되어야 한다. 큰 금액을 기준금액과 곱한 뒤 나누면 부동소수점으로 1원 작아질 수 있어 공통기준 비율로 직접 나눈다. 이 기대값은 별도 리터럴 테스트로 고정했다.
