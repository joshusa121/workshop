# 가업승계 공제 판정 — 최종 감사

Status: 구현 및 검증 완료. 2026-10-17 / 버전 2026-1. 실제 신고 적용 전 Josh 감수 필요.

## 구현 범위

- 상속과 생전 주식 증여를 구분해 기업·거주자·경영기간·지분·대표 재직·승계인·취임·신청/배제 요건을 충족/미충족/Josh 감수로 표시한다.
- 상속 한도 및 대상재산 중 작은 금액을 공제액으로, 증여는 한도 내 특례 과세가액에서 공제 후 누진세율을 적용한 산출세액으로 표시한다.
- 미확인 요건을 충족으로 간주하지 않으며 미확인·실패 시 실제 공제·세액 대신 요건 충족을 가정한 금액임을 명시한다.
- 금액은 공용 TraceValue, 기간·연령·비율·체크 항목과 사후관리 안내는 Traced를 받는 ScalarTrace로 근거를 연다. 모든 법령 링크는 사람용 law.go.kr 링크다.
- 세 단계 입력, 공유 URL(?s=), 형식·세율 버전 검사, noindex 보고서, 인쇄, 전제와 미반영, 작성일·버전·DISCLAIMER를 연결했다.

## 법령 확인

법제처 Open API 검색 후 네 법령의 MST로 XML 본문을 직접 수신했다. 법령 판본·조문·해시는 [확정 사실](family-succession-facts.md)에 기록했다. 상속 사전 종사는 2년, 대표 취임은 신고기한부터 2년, 증여는 증여일부터 3년으로 원문을 반영했다. 원문에서 확정하지 못한 수치는 엔진에 넣지 않았다.

## Josh 감수 및 미반영

- **기업·대상 재산의 실무 판정**: 업종 별표, 중소/중견 규모·독립성·자산총액, 최대주주·특수관계인 범위, 사업무관자산·과다보유현금·사택·대여금 예외 및 비상장 주식 평가. 이용자가 확인한 값을 입력하는 구조다.
- **다른 계산과의 결합**: 상속공제 종합한도와 전체 상속세, 사업무관자산·한도 초과분의 일반 증여세, 누적 증여·복수 수증자, 세액공제·기납부세액·연부연납·납부유예는 계산하지 않는다. 공제액은 절세액이 아니다.
- **예외와 시점**: 배우자 간주, 복수 기업, 기회발전특구, 합산 경영기간, 실제 승계일별 부칙, 조세포탈·회계부정 형 확정 및 후속 최대주주 승계 제한은 증빙을 포함해 Josh 감수 필요.
- **사후관리**: 상속의 5년/자산 40%/고용·급여 90% 요건과 증여의 취임·대표 유지·지분 유지 요건을 분리해 안내한다. 미래 이행 여부·정당한 사유·추징세액·이자상당액은 자동 판정하지 않는다.
- **끝수**: 증여특례 산출세액은 원 미만 버림의 표시 가정. 최종 납부세액 끝수 처리를 확정한 결과로 제시하지 않는다.

## 작업 경계

시작 시 origin 원격이 없어 git fetch origin은 실패했다. 원격 변경 유무는 확인하지 못했으며 푸시·머지는 하지 않았다. 제품 전용 파일만 커밋한다. catalog.ts·홈·shell·공용 테스트·설정·다른 제품·루트 status.md는 편집하지 않았다. TASK.md와 WORKER-DONE.md는 untracked로 유지한다. 카탈로그 연결은 오케스트레이터 작업이다.
