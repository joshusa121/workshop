# 증여 vs 상속 — 법제처 원문 대조 (7화)

작성: 세션 1, 2026-10-16. 상속세 및 증여세법 [시행 2026-01-02] (MST 276123), 시행령(MST 290845). 법제처 Open API 원문.

## 세율 (증여·상속 공통, 상증세법 §26, 증여는 §56이 §26 준용)
| 과세표준 | 세율 |
|---|---|
| 1억원 이하 | 10% |
| 1억원 초과 5억원 이하 | 1천만원 + (1억 초과액의 20%) |
| 5억원 초과 10억원 이하 | 9천만원 + (5억 초과액의 30%) |
| 10억원 초과 30억원 이하 | 2억4천만원 + (10억 초과액의 40%) |
| 30억원 초과 | 10억4천만원 + (30억 초과액의 50%) |

## 상속세 (사망 시)
- **기초공제** §18: 2억원.
- **그 밖의 인적공제** §20: 자녀·연로자·장애인 등(자녀 1인 5천만 등).
- **일괄공제** §21①: (기초공제 + §20① 인적공제) 합계와 **5억원 중 큰 금액**. 단 배우자 단독상속 시 §18+§20만.
- **배우자 상속공제** §19: 실제 상속액 기준(법정상속분 한도), 실제 상속액이 없거나 5억 미만이면 **5억원**. §24 한도.
- **세대생략 할증** §27: 상속인이 피상속인의 자녀를 제외한 직계비속(손자녀 등)이면 그 사람 몫 산출세액의 30%(미성년 40%).

## 증여세 (생전 이전)
- **증여재산 공제** §53: 배우자 **6억**, 직계존속 **5천만**(미성년 2천만), 직계비속 **5천만**, 4촌 이내 혈족·3촌 이내 인척 **1천만**. (수증자별 10년 합산)
- **혼인·출산 증여재산 공제** §53의2: 각 **1억원**(§53②와 별개, 합계 1억 한도).
- **과세표준** §55: 증여세 과세가액 − §53·§53의2 공제. **과세최저한 50만원**(§55②).
- **세율** §56 → §26 준용.
- **세대생략 할증** §57: 수증자가 증여자의 자녀가 아닌 직계비속이면 산출세액의 30%(미성년 & 20억 초과 40%).
