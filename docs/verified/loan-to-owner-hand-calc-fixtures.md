# 법인 가지급금 진단 — 독립 손계산 fixture

확인일 2026-10-17. 모두 가상 금액이며 고객 정보가 아니다. 엔진·다른 제품 코드를 사용하지 않고 법제처 XML 원문에서 산식을 확정한 뒤 Python Fraction의 유리수로 검산했다. 기대값은 테스트에 리터럴로 고정했다.

## 계산 순서

- 정상 이자 = Σ(잔액 × 일수) × 적용 연이자율 ÷ 365. 2026년 평년·단일 거래·12개월 사업연도 가정.
- 차액 = max(정상 이자 − 실제 이자, 0).
- 차액 ≥ 3억원 또는 차액 ≥ 정상 이자의 5%일 때 차액 전액 인정이자. 비교는 절사 전, 표시값은 원 미만 버림.
- 지급이자 부인 = 지급이자 × min(가지급금 적수, 총차입금 적수) ÷ 총차입금 적수. 차입금이 없고 지급이자도 없으면 0.
- 회사 과세소득 증가 = 인정이자 + 지급이자 부인. 조정 전후 과세표준에 국세·지방세 누진세율을 각각 적용해 차이를 구한다.
- 개인 소득처분 검토액은 인정이자만. 지급이자 부인액은 영 §106①3호마목의 기타 사외유출로 개인에게 더하지 않는다.

## 지급이자와 법인세율 경계

F12: 연평균 차입금 2억원, 지급이자 1천만원, 가지급금 1억원·365일, 실제 이자 0, 조정 전 법인 과세표준 199,000,000원.

1. 가지급금 적수 36,500,000,000원·일, 차입금 적수 73,000,000,000원·일.
2. 지급이자 부인 = 10,000,000 × 1/2 = **5,000,000원**.
3. 인정이자 4,600,000 + 부인 5,000,000 = **9,600,000원**. 조정 후 과표 208,600,000원.
4. 국세 전: 199,000,000 × 10% = 19,900,000원. 후: 20,000,000 + 8,600,000 × 20% = 21,720,000원. 증가 **1,820,000원**.
5. 지방세 전: 1,990,000원. 후: 2,000,000 + 8,600,000 × 2% = 2,172,000원. 증가 **182,000원**.
6. 회사 합계 **2,002,000원**, 개인 소득처분 검토액 **4,600,000원**. 개인 세액이 아님.

F13: 가지급금 1억원, 연평균 차입금 5천만원, 지급이자 3백만원. 차입금 한도를 적용하여 부인 = 3,000,000 × 1 = **3,000,000원**(초과 부인 금지).

F14: 기존 과표 19,999,000,000원, 소득 증가 4,600,000원. 200억원까지 1,000,000 × 20% + 그 위 3,600,000 × 22% = **992,000원**, 지방세 **99,200원**.

F15: 기존 과표 299,999,000,000원, 소득 증가 4,600,000원. 3천억원까지 1,000,000 × 22% + 그 위 3,600,000 × 25% = **1,120,000원**, 지방세 **112,000원**.

## 재현용 독립 Python 예시

```python
from fractions import Fraction
normal = Fraction(100_000_000 * 180 * 46, 1_000 * 365)
assert normal == Fraction(165_600_000, 73)
assert int(normal) == 2_268_493
assert 4_600_000 - 4_370_001 < Fraction(4_600_000, 20)
assert 4_600_000 - 4_370_000 == Fraction(4_600_000, 20)
assert 9_200_000_000 - 8_900_000_000 == 300_000_000
assert 1_000_000 * Fraction(20, 100) + 3_600_000 * Fraction(22, 100) == 992_000
assert 1_000_000 * Fraction(22, 100) + 3_600_000 * Fraction(25, 100) == 1_120_000
```

## Josh 대조용 입력 세트와 미검증

공식 계산기 **실측 미대조**. 이 진단과 같은 범위의 전용 공식 계산기는 이번 작업에서 이용하지 않았다. Josh는 F2/F4/F9/F12를 신고 조정명세서와 대조한다. 일수·원 미만 절사·거래 합산 단위는 Josh 감수 필요.

F16: 가지급금 1억원·180일, 연평균 차입금 2억원, 연간 지급이자 1천만원. 지급이자 부인 = 10,000,000 × (100,000,000 × 180) / (200,000,000 × 365) = 180,000,000 / 73 → **2,465,753원**. 분모에 가지급금 보유기간을 쓰면 안 된다.
