## 미반영과 Josh 감수 필요

1. 업무 관련성·특수관계인 해당 여부, 대여 거래의 합산 단위, 정상 이자율 적용 시점과 연중 개정 경과규정.
2. 가중평균차입이자율은 대여시점 기준으로 사용자가 확인해 입력한다. 차입금별 이자율 자동 산정, 소수 둘째 자리보다 정밀한 이자율, 장기대여 예외·당좌대출이자율 선택 신고와 이후 구속기간 자동 판정은 미반영.
3. 동일인 가수금의 일별 상계, 다른 업무무관 자산, 제외 차입금·지급이자 우선순위는 입력 전 감수 필요. 연말 차입금이 아닌 연평균 차입금을 입력해야 한다.
4. 실제 이자는 해당 기간의 세무상 수익 반영액이라는 전제. 미수이자 약정·회수, 원금 회수 가능성, 사외유출·귀속·처분 시기 판단은 미반영. 인정이자 전액을 언제나 즉시 상여로 처분한다는 확정 판단이 아니다.
5. 개인의 최종 소득세·지방소득세·건보료, 배당 가산·세액공제·금융소득 종합과세, 원금 상여 처분·대손 제한·증여세·가산세 미반영. 이를 0원 세금으로 표시하지 않는다.
6. 회사의 이월결손금·세액공제·특정 소규모법인(법 §60의2①1호)의 별도 세율·단기사업연도·외국세액·지방세 조례 가감 미반영. 2026년 12개월 일반 법인의 산출세액 증가 추정만 제공.
7. 끝수·초일/말일 산정·신고 명세서·공식 계산기 **실측 미대조**. 손계산 문서의 F2/F4/F9/F12로 Josh 최종 확인 필요. 실제 PDF 파일 인쇄·페이지 나눔은 미검증이며 인쇄 버튼 호출과 화면만 검증했다.
8. 카탈로그 등록·홈 노출은 편집 금지 지시에 따라 오케스트레이터가 처리한다. 원격 `origin`이 없어 fetch 및 원격 브랜치 차이 확인 불가. 푸시·머지·배포하지 않는다.
