# 쉬운 용어 표 — 화면 문구 순화 기준 (Josh 인터뷰 2026-09-26)

적용 범위: `src/components/corp-conversion/**`의 사용자 노출 문자열, `src/lib/tax/explain.ts`.
예외: 근거 팝오버(TraceValue의 steps·basis)와 검토보고서 「근거」 절은 세무사용이라 원래 용어를 쓴다.
전문 용어는 첫 등장 시 괄호로 1회 병기할 수 있다 — 예: "실제로 손에 남는 돈(가처분)".
테스트: `__tests__/plain-terms.test.ts` — 괄호 밖에 금지 용어가 남으면 실패. 세무사용 문자열은 같은 줄에 `plain-terms-ignore` 주석.

| 금지 용어 | 대체 표현 |
|---|---|
| 손금 | 비용(법인세 계산에서 빼주는 돈) |
| 익금 | 수익 |
| 산입 | 포함 |
| 상여 처분 | 대표 급여로 보아 과세 |
| 가지급금 | 회사가 대표에게 빌려준 것으로 보는 돈 |
| 과세표준 | 세금을 매기는 기준 금액 |
| 산출세액 | 계산된 세금 |
| 가처분 | 실제로 손에 남는 돈 |
| 유보 | 회사에 남겨둔 이익 |
| 결손 | 적자 |
| 필요경비 | 비용 |
| 손금불산입 | 비용으로 인정 안 됨 |

화면 라벨 적용 예:

| 이전 | 이후 |
|---|---|
| 대표자 가처분현금 | 대표 손에 남는 돈(가처분) |
| 법인 유보금 | 회사에 남겨둔 이익(유보금) |
| 합산 순자산 증가 | 대표 + 회사 합산 순자산 증가 |
| 유보 인출 시 2차 과세 추정 | 남겨둔 이익을 나중에 꺼낼 때 세금(2차 과세) |
| 가처분 기준 / 합산 순자산 기준 | 손에 남는 돈 기준 / 합산 순자산 기준 |

## 어미 규칙 (Josh 승인 2026-09-26)

- 사용자 노출 문장(설명문·해설·경고·힌트·홈 카피·헤더 카피·검토보고서 본문)은 **「~합니다」체**로 통일한다. 예: "법인 전환 시 총 부담은 N원 줄어든다." → "법인으로 바꾸면 총 부담은 N원 줄어듭니다."
- 문장이 아닌 명사구 라벨("대표 손에 남는 돈", "회수 없음", "— 전문가 확인")은 그대로 둔다.
- 예외(세무사용, 원래 문체 유지): 근거 팝오버의 steps 문자열과 basis description, 검토보고서 「근거」 절.
- 회귀 테스트: `__tests__/plain-terms.test.ts` 「어미」 절 — 대상 파일(홈·도구 페이지·컴포넌트·explain.ts·cutoff.ts·catalog.ts·goodwill/net-effect.ts)의 텍스트에서 "~다" 종결(「~ㅂ니다」 제외, 조사 「보다」「마다」 제외)을 찾으면 실패. 오탐은 같은 줄에 `tone-ignore` 주석.
