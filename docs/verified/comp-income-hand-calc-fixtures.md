# 종합소득세 엔진 — 손계산 fixture (4화)

독립 손계산(엔진과 별개로 계산) → `__tests__/comp-income.test.ts`로 고정. 2026년 귀속 기준.
공통: 과표 1원 버림·산출세액 10원 버림. 세액공제는 산출세액 한도.

## F1 프리랜서 기본(사업소득만)
수입 8,000만 / 경비 2,000만 → 사업소득 6,000만. 공제 기본(본인) 150만. 과표 5,850만.
산출세액 = 1,400만×6% + 3,600만×15% + 850만×24% = 84만+540만+204만 = **828만**.
세액공제 표준(사업) 7만 → 결정 **821만**. 지방 82.1만.
원천징수 3.3% = 8,000만×3.3% = 264만(국세 240만·지방 24만). 납부 **639.1만**.

## F2 배우자+부양가족2+경로우대+노란우산600만
기본 (1+1+2)×150만 = 600만. 추가 경로우대 1명×100만 = 100만. 노란우산 600만(수입 6천만 구간 한도 500만으로 clamp) = 500만.
공제 합계 1,200만. 과표 4,800만 → 산출 84만+510만 = **594만**. 세액공제 7만 → 결정 **587만**.
(노란우산 구간: 사업소득금액 6천만 이하는 500만 — 1화 `YELLOW_UMBRELLA_CAPS` 재사용)

## F3 겸업(근로 4천만 + 사업 3천만)
근로소득공제 = 750만 + (4,000만−1,500만)×15% = 1,125만 → 근로소득금액 2,875만. 사업소득 2,000만. 종합 4,875만.
과표 4,875만 − 150만 = 4,725만 → 산출 84만 + 3,325만×15% = **582.75만**.
근로소득세액공제: 근로분 산출세액 = 582.75만 × (2,875/4,875) = 343.65만(1원 버림 343.6538만).
  공제액 = 71.5만 + (343.6538만−130만)×30% = 135.5961만 → 한도(총급여 4천만: 74만−(4,000만−3,300만)×0.008 = 68.4만) 적용 → **68.4만**.
표준(근로) 13만. 세액공제 81.4만 → 결정 **501.35만**. 지방 50.135만. 원천징수(사업 3,000만×3.3%=99만). 납부 **452.485만**.
(주의: 근로 원천징수(연말정산 기납부)는 미반영 — 사업수입 기준 자동)

## F4 연금계좌세액공제 15% 구간
수입 4,000만 − 경비 1,000만 = 3,000만. 과표 2,850만 → 산출 84만+1,450만×15% = **301.5만**.
연금계좌 600만 납입, 종합소득금액 3,000만 ≤ 4,500만 → 15% = **90만**.
표준 7만 + 90만 = 97만 → 결정 **204.5만**. 지방 20.45만.

## F5 자녀 3명 + 부녀자 추가공제
수입 5,000만 − 경비 1,000만 = 4,000만. 기본 (1+3)×150만 = 600만. 추가 부녀자 50만. 과표 3,350만.
산출 84만+1,950만×15% = **376.5만**. 세액공제 표준 7만 + 자녀(3명: 55만+40만=95만) = 102만 → 결정 **274.5만**. 지방 27.45만.

## F6 성실신고확인비용 세액공제(한도 120만)
수입 3억 − 경비 1억 = 2억. 과표 1.985억.
산출 = 84만 + 540만 + 912만 + 2,170만 + 4,850만×38%=1,843만 = **5,549만**.
확인비용 200만×60% = 120만(한도 120만). 표준 7만 + 120만 = 127만 → 결정 **5,422만**. 지방 542.2만.

## F7 결손금(경비 > 수입)
수입 1,000만 − 경비 1,500만 → 사업소득 0, 결손 500만. 종합소득금액 0 → 공제 0, 과표 0, 산출 0, 결정 0, 지방 0.
원천징수 1,000만×3.3% = 33만 → 환급 **−33만**.

## F8 기납부세액 수동 입력 → 환급
수입 3,000만 − 경비 500만 = 2,500만. 과표 2,350만 → 산출 84만+950만×15% = **226.5만**. 세액공제 7만 → 결정 **219.5만**. 지방 21.95만.
기납부 300만(국세 round(300/1.1)=272.7273만, 지방 27.2727만) → 환급 **−58.55만**.
