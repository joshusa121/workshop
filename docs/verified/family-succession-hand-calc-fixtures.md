# 가업승계 독립 손계산 fixture

작성일 2026-10-17. 엔진을 호출하거나 결과를 복사해 기대값을 만들지 않고, 확정한 법정 한도와 산식으로 아래 값을 먼저 산출했다. 금액은 정수 원, 테스트에는 원 단위 상수를 직접 고정한다. 근거: [상증법 §18의2](https://www.law.go.kr/법령/상속세및증여세법/제18조의2), [조특법 §30의6](https://www.law.go.kr/법령/조세특례제한법/제30조의6).

상속 공제 = min(사업무관자산 등 제외 후 대상재산, 기간별 한도). 다른 요건은 충족 가정. 지분 보유 및 전체 대표 재직은 경영기간과 같게 설정.

| 사례 | 경영기간 | 대상재산 | 손계산 | 공제 예상 |
|---|---:|---:|---|---:|
| I1 | 9.99년 | 500억 | 10년 미만, 적용 불가 | 0 |
| I2 | 10년 | 500억 | min(500,300)억 | 300억 |
| I3 | 19.99년 | 500억 | min(500,300)억 | 300억 |
| I4 | 20년 | 500억 | min(500,400)억 | 400억 |
| I5 | 30년 | 700억 | min(700,600)억 | 600억 |
| I6 | 30년 | 70억 | min(70,600)억 | 70억 |

증여는 경영기간 10년, 한도 300억. 특례 과세가액 = min(대상재산,300억). 과표 = max(0,특례 과세가액−10억). 산출세액 = min(과표,120억)×10% + max(0,과표−120억)×20%.

| 사례 | 대상재산 | 과표 손계산 | 세액 손계산 | 특례 세액 예상 |
|---|---:|---:|---|---:|
| G1 | 9억 | max(0,9−10)=0 | 0 | 0 |
| G2 | 10억 | 10−10=0 | 0 | 0 |
| G3 | 130억 | 130−10=120억 | 120×10%=12억 | 12억 |
| G4 | 140억 | 140−10=130억 | 120×10%+10×20%=14억 | 14억 |
| G5 | 350억 | min(350,300)−10=290억 | 120×10%+170×20%=46억 | 46억 |
| G6 (20년) | 700억 | min(700,400)−10=390억 | 120×10%+270×20%=66억 | 66억 |
| G7 (29.99년) | 700억 | min(700,400)−10=390억 | 120×10%+270×20%=66억 | 66억 |
| G8 (30년) | 700억 | min(700,600)−10=590억 | 120×10%+470×20%=106억 | 106억 |

G5의 한도 초과 50억원 및 사업무관자산은 일반 증여세 별도 검토 대상이다. 표의 세액은 전체 납부세액이 아니다.
