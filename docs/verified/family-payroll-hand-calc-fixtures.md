# 가족 고용 — 독립 손계산 fixture

2026-10-17. 엔진 작성 전 법제처 원문의 속산식과 Python Decimal로 별도 계산했다. 엔진은 구간 누적 함수 `applyBrackets`를 쓰며, 이 표의 계산은 누진공제 속산식을 썼다. 표를 테스트의 정수 상수로 고정했다. 실제 인물·거래와 무관한 가상값이다.

## 독립 계산식

- T(x): 각 구간에서 x×세율−누진공제. 누진공제는 0 / 1,260,000 / 5,760,000 / 15,440,000 / 19,940,000 / 25,940,000 / 35,940,000 / 65,940,000원. 양수 원 미만 절사.
- L(x): 지방세 원문 구간에 x×세율−누진공제(국세 누진공제의 10%)를 적용 후 원 미만 절사. 절사한 T(x)의 10%로 역산하지 않음.
- D(g): 급여 구간에 따라 0.7g / 3,500,000+0.4(g−5,000,000) / 7,500,000+0.15(g−15,000,000) / 12,000,000+0.05(g−45,000,000) / 14,750,000+0.02(g−100,000,000). 원 미만 절사 후 한도 20,000,000원.
- 직원 공통 과표 b=max(0,g−D(g)−1,500,000−직원 국민연금).
- C(t,g): 산출세액 t≤1,300,000이면 0.55t, 초과하면 715,000+0.3(t−1,300,000). 원 미만 절사 후 총급여별 한도 적용(수치는 facts.md).
- 표준 방식 W₁=max(0,T(b)−C(T(b),g)−130,000).
- 보험공제 방식 W₂=max(0,T(max(0,b−직원 기타보험))−C(T(max(0,b−직원 기타보험)),g)).
- 직원 소득세 W=min(W₁,W₂), 지방세=floor(W/10). 보험공제와 표준공제는 중복하지 않음.
- 고용 후 과표 A=max(0,B−g−E+F). B: 사업주 고용 전 과표, E: 사업주 보험료, F: 종전 가족 공제를 실제 적용했고 g>5,000,000인 경우 1,500,000원.
- 순절약 = T(B)−T(A)+L(B)−L(A)−E−P−H−W−floor(W/10). P: 직원 국민연금, H: 직원 기타보험.

모든 행은 실제근무·급여적정·증빙·보험확인·직원 단일소득 요건을 확인한 상태. 기존 기본공제 적용 여부는 아래 표를 따른다. 근거: [소득세법 제47조](https://www.law.go.kr/법령/소득세법/제47조), [제50조](https://www.law.go.kr/법령/소득세법/제50조), [제55조](https://www.law.go.kr/법령/소득세법/제55조), [제59조](https://www.law.go.kr/법령/소득세법/제59조), [제59조의4](https://www.law.go.kr/법령/소득세법/제59조의4), [지방세법 제92조](https://www.law.go.kr/법령/지방세법/제92조).

### 2번 전개

D(24,000,000)=7,500,000+9,000,000×15%=8,850,000.
b=24,000,000−8,850,000−1,500,000−1,140,000=12,510,000.
표준 방식 산출세액=750,600, 근로공제=412,830, W₁=207,770.
보험공제 과표=11,510,000, 산출세액=690,600, 근로공제=379,830, W₂=310,770.
따라서 표준 방식 선택. 순절약=3,960,000+396,000−2,400,000−1,140,000−1,000,000−207,770−20,777=−412,547.

### 9번 전개

D(45,000,000)=12,000,000. b=29,362,500.
표준 방식 산출세액=3,144,375, 급여별 근로공제 한도=660,000, W₁=2,354,375.
보험공제 과표=27,362,500, 산출세액=2,844,375, 공제=660,000, W₂=2,184,375.
가계 보험료=8,637,500. 순절약=17,325,000+1,732,500−8,637,500−2,184,375−218,437=8,017,188.

4·5번은 국세가 원 미만 절사돼 감소액이 모두 0인 경계다. 6·7번은 단 1원으로 종전 가족 기본공제를 잃는 경우다. 8번은 사업주 과표를 음수로 내려 당기 환급을 만들어내지 않는지 확인한다. 0원 보험료는 계산 경계용 가상 입력이며 실제 가입 제외 사례를 의미하지 않는다.
