검색·본문은 모두 법제처 Open API, OC=<OC키>로 직접 조회했다. 블로그·기억·기존 계산기 상수는 근거로 사용하지 않았다. 법령 전체 시행일과 조문 시행일은 다를 수 있다. 아래는 API 응답의 조문 본문 발췌다.

적용: 2026년 귀속, 2026.1.1. 개시 1년 사업연도 내국법인. 종합과세는 본인 기본공제만 적용한 세액공제 전 증가액이며, 신고 납부세액이 아니다. 지방세는 표준세율만 반영한다. 사업연도별 적용례·개별 조례·등록주택 적격 판단은 Josh 감수 필요.

## 확정된 계산 값

- 개인: 과표 구간 1,400만/5,000만/8,800만/1.5억/3억/5억/10억, 세율 6/15/24/35/38/40/42/45%. 본인 공제 150만원.
- 주택: 총수입 2천만원 이하만 분리 선택. 미등록 경비 50%·추가공제 200만원, 적격 등록 경비 60%·추가공제 400만원. 추가공제는 임대 외 종합소득금액 2천만원 이하만. 국세 14%, 지방세 1.4%.
- 일반 법인: 2억/200억/3천억 경계, 10/20/22/25%. 소규모 임대 등 법인(법 §60의2①1): 200억/3천억 경계, 20/22/25%. 지방세 각 1/10 표준세율.
- 국내 일반 배당 국세 원천징수 14%, 지방 특별징수는 원천징수 국세의 10%. 금융소득 합계 2천만원 초과 시 최종 비교 차단.
- 국세 과표 원 미만, 국세·지방세 각 10원 미만 버림. 연간 단일 배당·납부 모형: 실제 지급회차 및 소액부징수 특례는 Josh 감수 필요.
