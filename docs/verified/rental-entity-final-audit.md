# 감수 보고서 — 부동산 임대 개인 vs 법인

검증일: 2026-10-17. 버전: `2026-10-17.1`.

구현 범위는 2026년 연간 임대 운영 비교다. 대표 급여 없는 1인 주주 모형이며, 개인은 세액공제 전 증가액, 법인은 법인세·법인지방소득세와 해당 연도 배당 원천징수액을 합산한다. 유보금의 미래 인출 세금은 포함하지 않는다. 법인 전환 자체를 추천하거나 신고 납부세액을 확정하는 도구가 아니다.

공식 홈택스 모의계산 **실측 미대조**. 원문과 손계산·자동 테스트만 확인했으므로 세무 항목을 실측까지 통과한 것으로 표기하지 않았다. Josh 대조용 가상 입력은 손계산 기록에 제공했다.

## 실행 검증

- `npx vitest run`: 42개 파일, 545개 테스트 통과. 제품 전용 테스트는 29개(표 fixture12개 포함).

- `npx next typegen` 후 `npx tsc --noEmit`: 통과. 최초 타입검사의 기존 `LayoutProps` 미생성 문제는 typegen으로 해소했으며 공용 파일을 수정하지 않았다.
- 제품 전용 경로·테스트에 대한 `npx eslint`: 통과. `git diff --check`: 통과.
- production 서버 포트3107에서 두 라우트 HTTP200 확인.
- Chrome 실제 브라우저: 입력 변경 → 개인·법인 금액 갱신 → 분기점 표시 → URL 재로드 복원 → 보고서 이동 확인. 근거 팝오버에서 법제처 링크 확인.

- 보고서 DOM `robots=noindex, nofollow`, 작성일·버전·인쇄 버튼 확인. 실제 인쇄/PDF 저장 대화상자를 통한 파일 출력은 미실행.
- 데스크톱 및 모바일390px 스크린샷 시각 검토. 모바일 계산기·보고서 모두 `scrollWidth=clientWidth=390`. 보고서 콘솔 error/warn 없음.
- 시각 자기비평: 요청한 3화의 좌입력/우결과 및 기존 캔버스·선·숫자 서체를 따랐다. 반복 카드 대신 세금 단계별 행을 사용했다. 큰 결과 금액은 작은 화면에서 세로로 배치해 비교 칸 밀집을 완화했다.

## 작업 범위 확인

- 시작 시 `git fetch origin`은 origin 미등록으로 실패. 원격 대비 확인 불가를 기록하고 로컬 브랜치에서 작업했다.
- 카탈로그·루트 page·shell·README·package/config·기존 report-render 테스트·다른 제품은 수정하지 않았다.
- 원래 untracked였던 `TASK.md`는 수정·커밋하지 않았다.
- 이 제품 경로와 테스트·검증문서·작업 기록만 커밋한다. 푸시·머지·배포는 하지 않는다.
- 카탈로그 등록(slug=`rental-entity`, number=`10`, name=`부동산 임대 개인 vs 법인`)은 오케스트레이터 후속 작업이다.
