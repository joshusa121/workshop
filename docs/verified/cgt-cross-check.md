## 대조로 확정된 것

- **보유기간은 취득일을 첫날로 센다(초일산입).** 처음 엔진은 "응당일에 n년"으로 셌으나, X5·X6에서 홈택스가 응당일 전날에 n년을 채우는 것으로 확인돼 엔진을 고쳤다(`period.ts`). "n년 이내" 기한(일시적 2주택 3년, 혼인·동거봉양 10년, 입주권 3년, 경과조치 4·6개월)은 실측 근거가 없어 Josh가 같은 방식(응당일 전날까지)으로 확정했다 — 기한 초일산입, Josh 확정 2026-09-26.
- **다주택 중과 유예 만료.** 홈택스 화면 문구가 "'22.5.10.~'26.5.9.까지 양도하는 경우 한시적으로 다주택자 중과 적용이 배제됩니다"와 경과조치(계약 2026-05-09까지, 4개월·6개월)를 그대로 안내한다. 원문(`cgt-facts.md` §2)과 같다. X2에서 중과 세액도 일치했다.
- **고가주택 안분식** "⑤ × (② − 12억) ÷ ②"가 시행령 §160①과 같다.

## 대조하지 못한 것 (남은 리스크)

- **장특을 반영한 최종 세액(F2·F4)**: 간편계산 화면에는 장특 금액 입력칸이 없고, 계산기 팝업의 값이 자동화 환경에서는 본 화면으로 넘어가지 않았다. 대신 장특 금액(팝업)과 과세대상 양도차익(본 화면)을 각각 대조했고, 나머지는 §55 누진 계산이라 X4와 1화 대조(`manual-cross-check.md` C-2)로 검증된 부분이다.
- **입주권·분양권·재건축(F7·F8)**: 간편계산은 "부동산 양도분에 한함"이고, 장특 계산기도 "재건축·재개발 신축건물·조합원입주권은 제공하지 않음"이라고 명시한다. 손계산 fixture로만 고정했다.
- **1세대 1주택 비과세 판정 자체(F1·F3)**: 간편계산은 비과세 여부를 사용자가 "예/아니오"로 고르게 해 판정 로직을 대조할 수 없다. 별도 「비과세·중과세 자가진단」 메뉴는 이번에 쓰지 않았다(다음 라운드).
- **스크린샷**: Aside repl의 파일 저장이 실패해 이미지는 남기지 못했다. 위 숫자는 결과 화면 본문 문자열을 그대로 옮긴 것이다.
- **지방소득세**: 간편계산 결과표에 지방소득세 행이 표시되지 않았다. 엔진은 산출세액 × 10%(3화는 세액공제가 없어 1화 R1 정정 후의 「결정세액 × 10%」와 동일).
