## B. 10년·1억원: 역환산

근속공제 1,500만원, C = 8,500만/10×12 = 1억200만원.
환산공제 = 6,170만 + 200만×45% = 6,260만원.
과표 3,940만원 → 84만 + 2,540만×15% = 465만원.
국세 465만/12×10 = 387만5천원, 지방세 38만7,500원, 합계 **4,262,500원**, 세후 **95,737,500원**.

## E. 임원 혼합구간: 전체 계산

퇴직금 5억원, 2012~2019 96개월, 2020 이후 72개월, 각 연평균 총급여 1억원.
한도 = 1억×1/10×96/12×3 + 1억×1/10×72/12×2 = 2억4천만 + 1억2천만 = 3억6천만원.
초과 **1억4천만원은 근로소득**이며 해당 세금은 별도다.

총 근속 168개월→14년, 근속공제 2,500만원.
C=3억3,500만×12/14=2,010,000,000/7.
환산공제=6,170만+(C−1억)×45%=1,021,400,000/7.
과표=floor(988,600,000/7)=141,228,571원.
환산세=15,360,000+(141,228,571−88,000,000)×35%=33,989,999.85원.
역환산=33,989,999.85/12×14=39,654,999.825원.
국세 **39,654,990원**, 지방세 **3,965,490원**, 합계 **43,620,480원**, 퇴직소득분 세후 **316,379,520원**.

## F. 2011년 이전 근무분

퇴직금 3억원, 전체 360개월(이전 180 + 2012~2019 96 + 2020 이후 84), 두 연평균 급여 5천만원.
이전분=3억×180/360=1억5천만원.
