# 작업실

현직 세무사가 상담에서 반복되는 질문을 하나씩 계산기로 만드는 연재입니다. 계산이 성립하는 것만 만들고, 모든 숫자는 법제처 원문 조문까지 거슬러 올라갈 수 있게 합니다.

> 본 계산은 참고용 시뮬레이션이며 세무 자문이 아닙니다. 개별 사안은 반드시 세무사 확인이 필요합니다.

## 오픈소스 공개

2026년 11월 2일부터 이 저장소를 공개합니다. 계산 엔진, 화면, 테스트, 그리고 법령 원문 대조·손계산·공식 계산기 실측 기록까지 개발에 쓴 자료를 그대로 엽니다.

- **계산 과정을 직접 따라가 볼 수 있습니다.** 세율·공제액 같은 법령 값은 `src/lib/tax/` 아래 제품별 `rates*.ts`(2화는 `goodwill/facts.ts`)에 조문·확인일과 함께 있고, 검증 기록은 `docs/verified/`에 있습니다.
- **MIT 라이선스입니다.** 상업적 이용을 포함해 자유롭게 쓰고 고칠 수 있습니다. 저작권 표시와 라이선스 문구만 남겨 주세요.
- **공개한 코드도 세무 자문이 아닙니다.** 코드를 가져다 쓰더라도 결과는 참고용이며, 각 화면의 「다루지 않는 것」 목록에 적힌 항목은 계산하지 않습니다.
- **틀린 곳을 찾으면 알려 주세요.** 방법은 아래 「기여」에 있습니다.

## 계산을 믿을 수 있게 하는 방법

- **법령 값은 원문으로만 넣습니다.** 세율·기준금액·공제율은 법제처 국가법령정보센터 원문으로 확인한 값만 코드에 들어갑니다. 코드의 모든 값에는 조문과 확인일이 붙어 있고, 빠지면 테스트가 실패합니다.
- **숫자마다 근거를 볼 수 있습니다.** 화면의 밑줄 친 숫자를 누르면 계산 과정과 근거 조문, 또는 "가정"이라는 표시가 나옵니다.
- **여러 번 확인합니다.** 모든 제품은 원문 대조와 엔진과 독립된 손계산을 거칩니다. 공식 계산기가 있는 경우 실측 대조까지 합니다. 지금은 1화(홈택스 퇴직·근로소득, 4대보험, 건강보험공단)와 3화(홈택스 양도소득세)가 실측 대조를 마쳤습니다. 나머지 제품은 공식 계산기가 없거나 아직 대조하지 못했고, 그 사실을 각 제품 감사 문서에 적어 두었습니다.
- **가정은 가정이라고 씁니다.** 기장료처럼 법령이 아닌 값은 "전제"로 따로 모아 보여 주고, 사용자가 고칠 수 있습니다. 계산하지 않는 항목은 화면의 "다루지 않는 것" 목록에 적습니다.

근거 문서는 `docs/verified/`에 있습니다. 파일 이름 앞부분은 제품 경로와 같습니다(예: `retirement-facts.md`는 9화). 예외로 1화는 접두어가 없고, 3화는 `cgt-`, 4화는 `comp-income-`을 씁니다.

## 실행

Node.js 20.9 이상이 필요합니다(Next.js 16 요구 사항).

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 계산 엔진·코덱·문구 규칙 테스트
npm run build
```

Next.js 16 App Router, React 19, Tailwind CSS 4, Vitest를 씁니다. 외부 서비스나 데이터베이스는 없고, 계산은 모두 브라우저에서 합니다.

## 구조

```
src/lib/tax/              1화 계산 엔진, 공통 세율(rates.ts)·근거(sources.ts)·누진세 계산
src/lib/tax/conversion/   1화 전환 방법·비용·회수기간·성실신고 판정
src/lib/tax/goodwill/     2화 계산 엔진
src/lib/tax/<제품>/        3~21화 계산 엔진. 폴더 이름은 제품 경로와 같고, 3화는 cgt/, 4화는 comp-income/
                          각 폴더에 engine.ts(계산, 3화는 cgt.ts)·rates*.ts(법령 값)·input.ts(입력 정리)·share.ts(공유 링크)·version.ts(세율 버전)
src/lib/catalog.ts        21편 목록과 제품별 세율 버전
src/app/tools/<경로>/      제품별 페이지와 인쇄용 검토보고서(report/)
src/app/review/           감수 시트 화면
src/components/           제품별 화면 구성 요소
__tests__/                테스트
docs/verified/            법령 원문 대조·손계산·공식 계산기 대조·감사 문서
```

세율을 고치면 해당 제품의 세율 버전도 올려야 합니다. 1화는 `sources.ts`의 `RATES_VERSION`, 2화는 `goodwill/facts.ts`의 `GOODWILL_RATES_VERSION`, 3~21화는 각 폴더의 `version.ts`에 있습니다. 버전을 올리면 예전 공유 링크를 연 사람에게 "세법 개정으로 결과가 달라질 수 있음" 안내가 나옵니다. 제품마다 법령 값의 지문을 버전과 함께 `__tests__/rates-version-guard.test.ts`에 고정해 두어서, 값만 바꾸고 버전을 올리지 않으면 테스트가 실패합니다. 1화와 공유하는 값(세율표·지방소득세율 등)을 바꾸면 그 값을 쓰는 제품이 모두 실패합니다. 다만 엔진(`engine.ts`) 안에 숫자를 직접 적은 값은 이 검사에 걸리지 않으므로, 법령 값은 반드시 `rates*.ts`에 둡니다.

## 기여

계산 오류나 법령 개정을 발견하시면 이슈로 알려 주세요. 근거 조문과 확인일을 함께 적어 주시면 가장 빠르게 반영할 수 있습니다. 세법 값을 바꾸는 변경은 원문 대조 문서와 테스트를 함께 고쳐야 합니다.
